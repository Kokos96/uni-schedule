## 1. Першопричина інциденту (`BUG-001`)

Перевірка живого HTML офіційного джерела ЛНУ (`dekanat.lnu.edu.ua/cgi-bin/timetable.cgi?n=700`, збережений фікстур `tests/fixtures/lnu-ina35s-2026-11-26-live.html`, 52 941 байт) для групи `ІНА-35с` (Факультет іноземних мов, 3 курс, Англійська філологія) встановила:

1. **Нефільтровані паралельні збірні підгрупи:** У HTML ЛНУ відсутні приховані атрибути підгруп для мовних пар — усі паралельні секції позначені однаковим `<span class="gr2_name">Збірна група</span>` і розрізняються лише за `(subject, teacher)`:
   - `Друга іноземна мова` містить 3 мови (`іспанська`, `німецька`, `французька`) та 10 різних викладачів у паралельних слотах.
   - `Перша іноземна мова` містить 14 різних викладачів у паралельних слотах.
   - У результаті в один понеділок (`2026-11-23`) рендерилося 23 перекриті блоки (172 за 2 тижні).
   - Крос-факультетний аудит 16 реальних кешованих груп ЛНУ підтвердив ту саму проблему для `ІНА-34с`, `ІНА-36с` і навіть для 1-го курсу Факультету електроніки (`ФЕП-13с` — паралельні секції `Іноземна мова`).
2. **«Аудиторію не вказано»:** У 166 із 172 блоків сирого HTML `ІНА-35с` тег `<span class="room_name">` фізично відсутній у джерелі ЛНУ (присутній лише в 6 блоках: `100/І`, `308/І`, `512/І`, `402/І`, `509/І`, `206/І`). Застосунок чесно відображає відсутність аудиторії й нічого не вигадує.

## 2. Реалізоване універсальне рішення

- **`src/utils/parallelGroups.ts`:** Універсальний детектор `detectParallelGroupDimensions()` (спільний для фронтенду та Worker Push-планувальника). Вимір створюється лише за наявності підтвердженого паралельного конфлікту (`>= 2` різних `(subject, teacher)` не-вибіркових пар без числової `subgroup`, `trackNumber` та кафедрального правила в одному слоті). Підтримує як вибір конкретної викладацької підгрупи (`opt_...`), так і мовного варіанту (`var_...`).
- **Сумісність `lesson.id`:** Ідентифікатори пар не змінено — історія відвідуваності, нотатки та дедлайни збережено повністю.
- **Динамічний UI (`ProfileSettingsSection.tsx`, `ScheduleView.tsx`):**
  - Картка «Мовні та паралельні підгрупи» на базі `PremiumSelect` (із пошуком) з'являється лише для груп із паралельними вимірами.
  - Для груп на кшталт `ФЕП-33с` (кафедри + числові підгрупи `1`/`2`) жодного зайвого UI не додається.
  - Якщо паралельні підгрупи ще не обрано, обов'язкові пари не зникають мовчки — показується неблокуючий банер із кнопкою «Обрати підгрупи».
- **Синхронізація та Push:** Додано `selectedParallelGroups` у `UserSettings`, `ProfileSyncQueue`, `apiClient`, `backup.ts`, `workers/api/src/routes/profile.ts`, `workers/api/src/push/scheduler.ts` та адитивну міграцію `0009_profile_parallel_groups.sql`.

## 4. Відомі обмеження джерела

- **Точкова одноразова заміна викладача в одному слоті:** Оскільки офіційний HTML ЛНУ не передає стабільного `subgroupId` або ознаки заміни, повна заміна викладача у завантаженому періоді автоматично виявляється (`staleDimensions`) без приховування пар, тоді як точкову заміну в одному окремому слоті (коли обраний викладач залишається в інших слотах періоду) неможливо однозначно відрізнити від слоту іншої підгрупи без припущень. У такому разі студент може тимчасово обрати режим «усі викладачі» або «показувати всі підгрупи».
- **Відсутні аудиторії:** 166 зі 172 блоків `ІНА-35с` не містять `<span class="room_name">` у першоджерелі ЛНУ; застосунок чесно відображає «Аудиторію не вказано».
- **Фізичний iPhone:** Верифікацію виконано в емуляції Playwright Chromium (`390×844`, `dpr=2`); перевірка на фізичному iPhone виконується після деплою.
