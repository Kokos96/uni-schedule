# Uni Schedule v4.2.0 — Premium Experience Update

Дата: 2026-11-26

## Основні зміни

### Stage A — Повне виправлення iOS-зуму, viewport та клавіатури
- **Виправлено автоматичний зум Safari:** у `src/index.css` гарантовано обчислений `font-size: 16px !important` для всіх мобільних текстових `<input>`, `<select>`, `<textarea>` та `[contenteditable="true"]` (`max-width: 1023px`), що не перекривається Tailwind-утилітами `text-xs` / `text-sm`.
- **Усунуто блокування відновлення масштабу:** видалено глобальний `gesturestart` `e.preventDefault()` з `index.html`, який блокував вихід із зуму у standalone PWA.
- **Keyboard-aware viewport (`src/hooks/useKeyboardViewport.ts`):** визначення віртуальної клавіатури через `focusin`/`focusout` + `Visual Viewport API` (відрізняє клавіатуру від pinch-zoom, автоматично вирівнює горизонтальний зсув після закриття клавіатури та плавно ховає `BottomNav` під час введення).

### Stage B — Signature Brand Reveal (2.5s App Launch)
- **Оновлено `AppSplash.tsx`:** оптично скоригований 136px логотип (обрізано ~11% прозорого поля `icon-512.png`), діагональна геометрична поява з тонким бурштиновим відблиском, типографічний словознак `Uni Schedule` із синхронізованим трекінгом без шаблонної розділової лінії, та збережений безперервний aperture-морфінг у реальний інтерфейс (~2500ms; ~300ms у `prefers-reduced-motion`).

### Stage C — Scroll-Driven Instagram-Grade Bottom Navigation
- **Новий `useScrollDockProgress` (`src/hooks/useScrollCompact.ts`):** неперервний scroll-driven `MotionValue` (0 ре-рендерів React під час скролу) з миттєвим розворотом при скролі вгору, м'яким доведенням після зупинки та захистом від iOS overscroll і програмного скидання скролу.
- **Пропорції `BottomNav.tsx`:** на 390px екрані — `356×58px` (розгорнута) → `292×50px` (компактна, стиснення 64px із мінімальною ціллю натискання ≥44×44px), інтегрований індикатор на 5-колонковій локальній сітці без `ResizeObserver`, приховування під час відкритої клавіатури.

### Stage D & E — Кастомні академічні селектори та надійність профілю
- **Новий портальний `PremiumSelect.tsx`:** тема-узгоджений Bottom Sheet на мобільних і viewport-aware Popover на десктопі (`createPortal` у `document.body`, `z-[90]`) — повністю усуває перекриття списку груп карткою «Підгрупа» та замінює системні iOS `<select>`.
- **Перегляд груп без клавіатури:** натискання поля групи одразу показує підтверджені групи без відкриття клавіатури; пошук винесено в окреме 16px поле всередині шторки.
- **Гідратація профілю:** додано `isHydratingRemoteProfile` у `useSettings.ts`, щоб уникнути миготіння онбордингу під час відновлення серверного профілю.

### Технічні оновлення
- Service Worker кеш оновлено з `v12` до `v13` (без очищення даних користувача).
- База даних D1 (`0001`–`0008`) та бекенд-контракти повністю збережені; нових міграцій D1 не потрібно.
