# Release Notes — Uni Schedule `v3.5.1`

## Summary
Uni Schedule `v3.5.1` fixes first-launch profile hydration, adds unique prefix matching for LNU group names (e.g. `ІНА-34` → `ІНА-34с`), and guides users to select ДВВС electives when a synced schedule contains only elective courses.

## Fixed
- **Unique prefix group resolution (`src/components/settings/UniversitySelectorCard.tsx`):** Typing a group prefix like `ІНА-34` when a single matching group (`ІНА-34с`) exists in the loaded faculty list automatically resolves and selects `ІНА-34с` instead of failing with `502`.
- **ДВВС empty-state prompt (`src/App.tsx`, `ScheduleView.tsx`, `WeekGridSection.tsx`, `WeekGrid.tsx`):** When a synced live schedule has available ДВВС electives (`availableElectives.length > 0`) and none are selected yet (`selectedElectives.length === 0`), Day and Week views display a clear prompt (`Потрібно обрати ДВВС`) with a direct button (`Обрати ДВВС в Опціях`) instead of showing an empty timetable.
- **First-launch profile hydration (`src/hooks/useSettings.ts`):** Avoids forcing the unedited backend default `student_profiles` row (`lnu / 1005 / ФЕП-33с`) when no `uni_schedule_cached_group_v2` cache exists locally, keeping the built-in schedule usable on first visit.
