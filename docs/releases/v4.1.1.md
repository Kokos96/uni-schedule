# Uni Schedule v4.1.1 — Academic Reliability & Premium Launch Experience

Дата: 2026-11-25

## Основні зміни

### Stage A — Надійна активація академічної групи
- **Виправлено життєвий цикл запиту в `useScheduleSource.ts`:** усунуто render-time інвалідацію `requestSeqRef` / `activeSourceRef`, через яку `setSyncStatus('syncing')` переривав in-flight запит до коміту нового профілю.
- **Чітке розділення активного та очікуваного профілів:** додано `activateGroupSchedule` із монотонним лічильником покоління запиту, захистом від перегонів та збереженням попереднього валідного розкладу при помилці.
- **Стабільність чернетки та канонічна ідентичність:** `UniversitySelectorCard` синхронізує чернетку лише при реальній зміні закоміченого профілю (не скидається при зміні ДВВС/теми/підгрупи), зберігає канонічний ID групи та підтримує підтверджені порожні розклади (з `coveredFrom`/`coveredTo`).

### Stage B — Суворий підтверджений довідник ЛНУ
- **Новий перевірений каталог `src/data/lnuAcademicCatalog.ts`:** префіксні відповідності факультетів і спеціальностей ЛНУ на базі офіційних сторінок `electronics.lnu.edu.ua`, `lingua.lnu.edu.ua`, `ami.lnu.edu.ua`, `lnu.edu.ua` із джерелом походження (`provenance`).
- **Поточне покриття каталогу:** 276 із 1752 груп ЛНУ (15.8%) підтверджено; 1476 груп залишаються непідтвердженими та доступні через окремий режим глобального пошуку (`includeAll=1`).
- **Сувора фільтрація на сервері та клієнті:** при виборі факультету або спеціальності повертаються виключно підтверджені групи (наприклад, `ІНА-*` більше не з'являються у ФЕКТ, а `ФЕП-*` — у факультеті іноземних мов).
- **Окремий режим глобального пошуку:** `includeAll=1` відокремлено від фільтрації по факультету; вибір групи іншого підтвердженого факультету автоматично узгоджує ієрархію профілю.
- **Захист метаданих D1:** сервер більше не перезаписує `university_groups.faculty_id` та `course` недовіреними параметрами користувача, відхиляє суперечливі пари факультет/група (`400 ACADEMIC_MISMATCH`) та перевіряє сумісність факультету у stale-кеші.
- **Адитивна міграція:** додано `workers/api/migrations/0008_academic_catalog_metadata.sql` та консервативний скрипт очищення `docs/migrations/v4.1.1-repair-university-groups.sql` (не запускати в продакшені без підтвердження власника).

### Stage C — Повний редизайн запуску застосунку (Brand-to-Interface Morph)
- **Єдиний контролер запуску (`AppSplash.tsx`):** усунуто передчасне завершення під час зміни фаз та забезпечено сумісність із React StrictMode (`brand → settle → morph → content → done`, ~2500ms; ~320ms для `prefers-reduced-motion`).
- **Оновлена бренд-композиція:** 124px логотип без зайвої вкладеної рамки, 30px типографіка `Uni Schedule`, безперервна бурштинова лінія та вертикальний aperture-морфінг у реальний інтерфейс застосунку.
- **Синхронізація компонентів:** `AppShell` та `BottomNav` координовано з'являються після фази `morph`, із захистом фокусу та кліків під час сплешу.

### Stage D — Редизайн нижньої навігації (`BottomNav`)
- **Єдина геометрична модель:** прибрано `ResizeObserver`, який конфліктував із пружинами ширини. Єдиний `compactProgress` синхронно керує шириною (~358px → ~306px на 390px екрані), висотою (`58px → 52px`), відступами та масштабом іконок.
- **Математично прив'язаний індикатор:** 5-колонкова нормалізована сітка утримує індикатор точно на активній вкладці під час стиснення, розширення та швидкого перемикання вкладок.
- **Покращений `useScrollCompact`:** захист від iOS overscroll та придушення осциляцій при програмному скиданні скролу під час перемикання вкладок.

### Технічні оновлення
- Service Worker кеш оновлено до `v12`.
- `public/manifest.json` приведено до універсального брендингу `Uni Schedule`.
